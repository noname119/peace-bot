# Юзербот-ассистент и медиатор

Юзербот работает в одном выбранном чате, учитывает контекст, ведёт долговременную память и сам решает, когда вмешаться. Он помогает как ассистент и останавливает грубость, но не отвечает за участников.

## Как работает

- Никаких regex-триггеров. Все решения принимает LLM по контексту последних сообщений и долговременной памяти.
- Бот просыпается не на каждое сообщение, а после N новых сообщений. N выбирает сам бот на каждом пробуждении: от 1 до 15. Если разговор активный, он может просыпаться каждое сообщение; если тихий — реже.
- Пробуждение не означает ответ. На каждом пробуждении бот решает: написать сообщение или промолчать. Если пользы нет, он молчит.
- Если сообщение является ответом (reply) на сообщение бота, бот просыпается сразу, не дожидаясь N.
- На пробуждении бот видит: долговременную память, последние 100 сообщений чата и число новых сообщений. Он может ответить, помочь с вопросом или планом, остановить грубость, обновить память и выбрать следующее N.
- Бот различает участников: в контексте они подписаны именами и @username. `Я` — владелец аккаунта, `Бот` — сам бот, остальные подписи — собеседники.
- Все сообщения бота начинаются с 🤖.

## Активация

```
!activate
```

- Команду отправляете вы, с аккаунта юзербота. Чужие `!activate` игнорируются.
- Активным может быть только один чат. `!activate` в другом чате переносит бота туда.
- `!deactivate` останавливает бота; команду можно отправить в любом чате, включая «Избранное».
- `!reset` очищает память и контекст активного чата: факты и последние сообщения удаляются, бот начинает заново с новых сообщений.
- Команды удаляются из чата. Подтверждение приходит в «Избранное» с 🤖.
- Активный чат хранится в `state.json` и переживает перезапуск.

## Память

- В `memory.json` для каждого чата хранятся долговременные факты и последние 100 сообщений.
- Факты обновляет сам бот на пробуждениях: имена, отношения, предпочтения, договорённости. Мелочи и эмоции момента он не записывает.
- Память переживает перезапуск и возвращается при повторной активации чата. Команда `!reset` очищает её полностью.
- На первом запуске бот подгружает последние 100 сообщений чата из Telegram, чтобы сразу понимать контекст.
- Память и контекст локальные, но на каждом пробуждении они отправляются вашему LLM-провайдеру.

## Роль ассистента

Бот может:

- отвечать на вопросы и объяснять;
- помогать с планами, текстами и формулировками;
- напоминать договорённости из памяти;
- вмешиваться, когда в переписке появляется грубость или колкости;
- молчать, когда его участие не нужно.

Он не говорит за участников, не приписывает им слова и не выдумывает факты.

## Запуск

1. Нужен Python 3.10+.
2. Зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Заполните `.env` (`TG_API_ID`, `TG_API_HASH`, `OPENAI_API_KEY`).
4. Запустите:

   ```powershell
   python main.py
   ```

   При первом запуске Telethon попросит номер телефона и код. Сессия сохранится в `userbot.session`.

5. В нужном чате отправьте `!activate`.

## Настройки `.env`

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `TG_API_ID` | — | `api_id` с my.telegram.org |
| `TG_API_HASH` | — | `api_hash` с my.telegram.org |
| `SESSION_NAME` | `userbot` | Имя файла сессии |
| `OPENAI_BASE_URL` | `https://api.deepseek.com/v1` | Адрес OpenAI-совместимого API |
| `OPENAI_API_KEY` | — | Ключ. Без него бот не работает |
| `LLM_MODEL` | `deepseek-flash` | Модель |
| `LLM_TIMEOUT` | `60` | Таймаут запроса к LLM, секунды |
| `LLM_THINKING` | `1` | Включить режим размышления DeepSeek |
| `LLM_REASONING_EFFORT` | `high` | Усилие размышления: `low`, `high` или `max` |

Бот использует режим размышления DeepSeek: модель сначала строит цепочку рассуждений, затем отвечает. `LLM_REASONING_EFFORT` управляет глубиной (`low`, `high`, `max`); чем выше, тем дольше и дороже пробуждение. Для сторонних OpenAI-совместимых провайдеров отключите `LLM_THINKING` и поменяйте `LLM_MODEL`.

## Ограничения

- Без доступного LLM бот молчит: после ошибки он ждёт 60 секунд и пробует снова.
- Интервал пробуждения выбирает модель. Если она поставила 15, обычное сообщение может не разбудить бота до накопления 15 новых; ответы (reply) на его сообщения будят сразу.
- Модель может ошибаться в оценке контекста и фактов. Важные договорённости лучше дублировать вручную.
- Сообщения уходят с вашего аккаунта и помечены 🤖: отдельного бота нельзя добавить в личную переписку.
- Юзербот работает от вашего личного аккаунта. Автоматизация аккаунта — зона риска по правилам Telegram.
- `memory.json` содержит фрагменты переписки и факты. Не публикуйте его.

## Структура проекта

```
main.py       клиент, активация, счётчик пробуждений, отправка
brain.py      промпт, решение speak/молчать, интервал N, обновление памяти
memory.py     долговременная память и последние сообщения
state.py      активный чат
config.py     чтение .env
state.json    активный чат
memory.json   память и контекст по чатам
userbot.session  сессия Telegram
```
